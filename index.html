Ajout manuel d'un animal

1. Importer la liste des inscrits

Fichier fourni par l'organisateur ou le partenaire. Le n° de cheptel et la date de naissance peuvent être absents. Le n° bovin sert de clé de rapprochement avec le fichier métier.
Entêtes conseillées pour optimiser l’import :
NUMANIM · DATE_NAISS · N°Travail · DETENTEUR
Si le fichier contient également un n° cheptel/EDE, une colonne contenant des valeurs à 8 chiffres sera reconnue automatiquement. Ces intitulés sont recommandés, mais ils ne sont pas obligatoires : l’import essaie aussi d’identifier les colonnes d’après leur contenu.
Colonnes reconnues automatiquement, notamment : N° ANIMAL, N°CHEPTEL, Propriétaire, DATE NAISSANCE, ainsi que les variantes usuelles. Les CSV Windows/ANSI sont acceptés.

2. Exporter les n° bovins pour extraction métier

Le CSV contient uniquement une colonne bovin.

3. Importer le fichier bovins métier

Ce fichier sert à compléter et contrôler les animaux déjà inscrits : détenteur, n° cheptel et date de naissance. Aucun nouvel inscrit n'est créé automatiquement à partir du fichier métier.

Qualifications des cheptels

Préparer les extractions qualifications

Exporte les n° EDE du concours pour faire les extractions dans ton logiciel métier.

IBR

Conforme uniquement si la qualification active est AA ou A et sans date de fin.

BVD

Non conforme si une qualification NS, NC, I1, I2 ou I3 est présente sans date de fin. Un cheptel absent du fichier BVD est considéré conforme.

Brucellose / Leucose / Tuberculose — SIGAL

Pour chacune des trois qualifications, conforme uniquement si le code vaut OI.
