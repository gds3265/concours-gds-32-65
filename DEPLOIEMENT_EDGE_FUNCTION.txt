SUIVI DES CONCOURS v0.6.1
INVITATIONS PARTENAIRES + DEPARTEMENTS

1) EXECUTER LE NOUVEAU SQL_SETUP.sql
   Il ajoute :
   - departements[] dans concours_acces_partenaires
   - invitation_envoyee_at

2) REDEPLOYER L'EDGE FUNCTION
   La fonction create-partner-account a changé.
   Dans Supabase > Edge Functions > create-partner-account :
   remplacer le code par :
   supabase/functions/create-partner-account/index.ts
   puis redéployer.

3) CONFIGURER L'URL DE RETOUR DES EMAILS
   Dans Supabase > Authentication > URL Configuration :
   - Site URL : mettre l'adresse de l'application GitHub Pages
   - Redirect URLs : ajouter l'adresse exacte de l'application
     Exemple :
     https://gds3265.github.io/concours-gds-32-65/

   Sans cette autorisation, le lien reçu par email peut ne pas revenir correctement vers l'application.

4) UTILISATION COTE GDS
   Onglet Partenaires :
   - choisir le concours
   - organisme
   - email
   - type
   - choisir Tous les départements OU cocher 32 / 65 / autre
   - choisir les contrôles dont le partenaire est responsable
   - cliquer "Envoyer l'invitation par email"

5) UTILISATION COTE PARTENAIRE
   - le partenaire reçoit un email Supabase
   - il clique sur le lien
   - l'application affiche "Créer mon mot de passe"
   - il choisit son mot de passe
   - il arrive ensuite directement dans son espace partenaire

6) PERIMETRE
   Le partenaire ne voit que :
   - le ou les concours auxquels son email est rattaché
   - les bovins des départements qui lui sont attribués
   - les contrôles cochés dans ses droits

7) ANCIENS PARTENAIRES
   Un tableau departements vide signifie "Tous les départements".
   Cela évite de casser les invitations déjà créées.
