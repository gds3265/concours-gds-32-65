SUIVI DES CONCOURS v0.5.2
Création sécurisée de comptes partenaires depuis l'application

1) EXÉCUTER SQL_SETUP.sql
   Cela ajoute :
   - auth_user_id dans concours_acces_partenaires
   - la table concours_admins

2) AUTORISER TON COMPTE GDS À CRÉER DES PARTENAIRES
   Dans Supabase > SQL Editor, exécuter en remplaçant l'email :

   insert into public.concours_admins(user_id,email)
   select id,email from auth.users
   where email='VOTRE_EMAIL_GDS'
   on conflict (user_id) do update set email=excluded.email;

   Faire la même chose pour chaque collègue interne qui doit pouvoir créer des comptes partenaires.

3) DÉPLOYER L'EDGE FUNCTION
   Le dossier fourni est :
   supabase/functions/create-partner-account/index.ts

   Avec Supabase CLI :
   supabase functions deploy create-partner-account

   Les variables SUPABASE_URL, SUPABASE_ANON_KEY et SUPABASE_SERVICE_ROLE_KEY
   sont disponibles côté Edge Function / projet Supabase.
   NE JAMAIS mettre SUPABASE_SERVICE_ROLE_KEY dans index.html ou GitHub Pages.

4) GITHUB PAGES
   Remplacer les fichiers habituels de l'application par ceux de la v0.5.2.

5) UTILISATION
   Onglet Partenaires :
   - choisir le concours
   - organisme
   - email
   - mot de passe initial (8 caractères minimum)
   - type + droits
   - cliquer "Créer le compte + inviter"

   Le partenaire peut ensuite se connecter avec cet email + ce mot de passe.
   À sa connexion, l'application bascule automatiquement sur son espace partenaire.

IMPORTANT
Le mot de passe initial n'est jamais enregistré dans les tables de l'application.
Il est transmis une seule fois à l'Edge Function qui crée le compte Supabase Auth.
